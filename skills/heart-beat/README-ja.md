# heart-beat

証明が完成するまで agent を自律的に働かせ続ける Claude Code スキル。
セッションがアイドルになったら cron のハートビートで起こす。

## 使い方

こう言う：

```
heart-beat 10分
```

すると agent は次の指示を受けたように動く：

> ハートビートを CronCreate で 10 分に設定して証明完成するまで自律的に動いて。
> この 10 分というのは 10 分ずつに仕事を区切れという意味ではなくて 10 分以上
> アイドルにしたくないという意味の 10 分。作業自体は何分でも連続して継続して下さい。

## 仕組み

1. agent は古い heart-beat ジョブを消し、繰り返しの `CronCreate` ジョブを
   1 つ作る（X = 10 なら `3-59/10 * * * *`）。
2. すぐに証明の作業を始め、そのまま続ける。
3. cron ジョブはセッションがアイドルのときだけ発火する。だから何かの理由で
   ターンが終わっても、X 分以内に次のハートビートが agent を起こし、続きから
   再開する。
4. 証明が完成したら（チェッカーが通り、`sorry` が残っていない）、agent は
   ジョブを消して、まとめを返す。

## 注意

- ジョブはセッション内だけ。Claude Code を終了すると消える。
- 繰り返しジョブは 7 日で自動的に期限切れになる。
- 「heart-beat を止めて」と言えば止まる。

cron の対応表とハートビートのプロンプトの正確な内容は [SKILL.md](SKILL.md) を参照。
